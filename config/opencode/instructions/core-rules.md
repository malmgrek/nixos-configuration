# Documentation Files
- ONLY create or edit README.md unless explicitly requested
- NEVER automatically create: QUICKSTART.md, INDEX.md, GUIDE.md, TUTORIAL.md, CONTRIBUTING.md, or other .md files
- If user says "document this", update README.md and ask if they want separate files

# Efficiency
- Report outcomes, not process steps
- Don't narrate tool usage ("Let me read...", "Now I'll...")
- Trust your tools - don't verify operations that succeeded without errors
- Don't re-check what just worked
- Stop when the task is complete

# Brevity
- One completion message at the end
- Include file:line references for changes
- No redundant confirmations
- No stream-of-consciousness narration
